# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security problems.

Email **tech@dotswan.com** with:

- a description of the issue and its impact,
- steps to reproduce (a minimal panel setup or failing test is ideal),
- the affected package versions (`dotswan/eagle-eye-filament`, `dotswan/eagle-eye`, Filament, Laravel).

We aim to acknowledge reports within three business days and will keep you informed while we work on a fix. Once a fix is released we will credit you in the changelog unless you prefer to stay anonymous.

Issues in the core package (capture, redaction, storage, drivers) belong to [`dotswan/eagle-eye`](https://github.com/dotswan/eagle-eye); you can still report them to the same address.
